# Contribuições

O Aurora é um projeto pessoal e de portfólio. O código está aberto para leitura e estudo, mas **não aceito
pull requests** com código, textos ou imagens de outras pessoas.

Isso mantém todo o código com um único autor, o que deixa livre a decisão de oferecer o app comercialmente no
futuro. Pull requests abertos serão fechados sem revisão.

Achou um erro ou tem uma ideia? Abra uma **issue** descrevendo o problema. Ideias podem inspirar mudanças, mas o
código é sempre escrito por mim.

Para segurança (uma falha que exponha dados de alguém), não abra issue pública: use o
[aviso privado de vulnerabilidade](../../security/advisories/new) do GitHub.

---

**Contributions:** this is a personal, source-available project. Pull requests are not accepted; issues are welcome.
